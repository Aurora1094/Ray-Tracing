## 📖 项目简介
本项目为南开大学计算机大类《高级语言程序设计》课程实验项目，由 **赵宇哲（学号：2411094）** 独立开发。

项目实现了一个基于 **Phong 光照模型**的面向对象**光线追踪（Ray Tracing）渲染器**。通过模拟光线在三维空间中的传播、碰撞、反射以及阴影计算，生成具有真实感的光影渲染效果，并结合 Qt 框架设计了直观的交互式 UI 界面。

## ✨ 核心特性
* **面向对象设计**：高度封装了向量（`Vector3`）、球体（`Sphere`）、光源（`Light`）、光线（`Ray`）等基础物理与几何计算类。
* **光线追踪核心算法**：基于“光路可逆”原理，计算相机发出的光线与场景物体的交点。最大递归深度限制为 3 次，完美兼顾了渲染效果与计算性能。
* **Phong 光照模型**：通过调节环境光（Ambient）、漫反射（Diffuse）和镜面反射（Specular）参数，真实还原不同材质在光照下的物理表现。
* **物理光学效果**：
  * **碰撞与反射**：支持递归反射追踪，并针对特定材质（如布料或地面）进行光线强度调整。
  * **自然阴影（Shadow Ray）**：采用射线投射法，精确计算物体表面到光源的遮挡情况。
* **抗锯齿处理（2x2 MSAA）**：在每个像素内进行 4 个子像素偏移采样并求取颜色平均值，有效消除了图像的边缘锯齿，显著提升画质。
* **可视化交互 UI**：支持动态调节相机位置、光源坐标，以及球体的材质、颜色、半径、反射率等参数，用户可以实时预览参数改变后的渲染结果。

## ⚙️ 核心技术原理
* **光线碰撞检测**：利用点线距离公式求解一元二次方程，以判断光线与球体是否相交，并修复了光线反向延伸导致视野外球体错误显示的逻辑 Bug。
* **递归光照计算（`traceRay`）**：将直接光照与反射光照相叠加（`directLight + reflectedLight`），支持材质反射率计算以及特定材质的能量衰减。
* **阴影射线剔除**：在投射阴影射线时，排除了物体自身的阴影检测，避免了误判自身遮挡的问题，并排除了特定反射情况下的地面阴影处理。
* **抗锯齿坐标映射**：将屏幕像素的离散坐标（包含子像素偏移）通过反函数思想转化为世界坐标系下的连续坐标，从而计算多次光线采样的均值。
